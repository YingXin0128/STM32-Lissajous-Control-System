## 与历史描述不一致或容易误读之处

1. 没有提供简历，无法逐句核对；本次没有将简历或聊天当成证据。
2. F103 实际工程是 ZE，不是旧 AD9910 供应商头注释所写 RCT6；F407 是 ZGTx，不能用旧 DebugConfig 的 VETx 判断。
3. 实际框架是标准外设库与 CMSIS，不是 HAL / CubeMX。
4. DDS 是 GPIO 模拟串行写；硬件 SPI2 负责 LCD。
5. “自动模式”只有状态和空服务，“三板视觉接口”是独立草案/实验，不是当前控制固件已接通的反馈环。
6. 未找到 RMS、DAC/VCA810 增益闭环或完整衰减网络实现。继电器 PD2 菜单旁路有代码，但不能据此扩展功能。
7. 菜单 1–4V 与配置单端标称值不同；峰峰值传输为 counts。README 没有写成已标定最终输出电压闭环。
8. 旧工程重建说明统称 ARMCC 5.06 update 5，但 F407 工程字段为 5.06 update 7；本机实际构建为 5.05 update 1。三者分别记录，不修改原配置来伪造一致。
9. 系统文件的 F407 HSE_VALUE 为 8 MHz，PLL 配置对应 168 MHz；工程 Cpu 描述 CLOCK(12000000) 不是实际运行时钟证据。
